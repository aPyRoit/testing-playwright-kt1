# Playwright-тесты Food.ru

Проект проверяет существующий сайт [Food.ru](https://food.ru/).

## Полное описание тестового сценария

Созданы три отдельных теста; в каждом по три явных шага.

1. **Text presence**
   - Открыть Food.ru.
   - Проверить заголовок страницы.
   - Проверить видимый текст «Рецепты» в шапке.

2. **Interactive elements**
   - Открыть главную страницу.
   - Ввести «Шарлотка» в поле «Что вы хотите приготовить сегодня?» и проверить значение.
   - Нажать «Найти», проверить переход к поисковой выдаче и наличие текста «Шарлотка: результаты поиска».

3. **Page change**
   - Открыть главную страницу.
   - Нажать карточку рецепта шарлотки.
   - Проверить адрес страницы рецепта и наличие раздела «Ингредиенты».

## Запуск в WSL

Выполнить npm ci, затем npx playwright install chromium и npm test.

После успешного прогона снимок страницы сохраняется в test-results/food-ru-recipe.png.
